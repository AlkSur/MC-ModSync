# C端使用教程（玩家侧）

你是玩家。整个更新过程只有一步：**双击"更新mod"**。

## 〇、你需要哪些文件（玩家端包内容）

压缩包解压后是这些，**一个都不能少**：

```
<游戏实例目录>\
├── mods\                    ← 你原有的 mod 文件夹（判断"放对了没"就看它在不在同级）
├── 更新mod.bat              ← Windows：双击这个
├── 更新mod.sh               ← Linux / macOS：运行这个
├── SHA256SUMS.txt           ← 校验清单（可选，用来确认文件没损坏）
└── _updater\                ← 更新器本体，整个文件夹要有
    ├── config.json          ← 服主已经填好（CDN 地址 + 包标识 + 公钥），不用你改
    ├── mcmodsync.exe        ← Windows 主程序
    └── mcmodsync.py         ← 纯 Python 兜底（exe 被杀软删了时用）
```

放置规则只有一条：**`更新mod.bat` 和 `_updater\` 要和 `mods\` 在同一层**。

- 常见目录：`.minecraft\`（没有版本隔离）
- 开了版本隔离：`.minecraft\versions\<版本号>\`

`更新mod.bat` 会把它**自己所在的目录**当作游戏目录，所以你把它放在哪一层，它就在哪一层的 `mods\` 里干活。**不要放进 `mods\` 里面**。

**你不需要配置任何东西**：`_updater\config.json` 里的地址与公钥由服主打包时写入，直接可用。也不需要手动下载任何 mod——双击后脚本自己去下载。

### 手上没有现成压缩包？

玩家端**必须由服主生成后分发**，不要试图从源码里手工拼——原因是 `_updater\config.json` 里写着你这台服务器的专属地址和公钥，拼错了更新器会拒绝工作（退出码 2 或 7）。

**服主侧：生成玩家端包**

```powershell
# 1) 先生成玩家端文件（会渲染 config.json）
mcmodsync package-client
# 产物在 dist\client-package\

# 2) 再打成压缩包（同时也会生成 A 端、B 端的包）
python tools\make_release.py
# 产物在 dist\release\MC-ModSync-C端-玩家更新器-v<版本>.zip
```

**玩家侧：拿到包之后**

解压 → 把里面全部内容放进游戏实例目录（与 `mods\` 同级）→ 双击 `更新mod.bat`。不需要任何配置。

### 关于"版本号"

玩家端会看到两个版本号，含义不同：

| 版本 | 是什么 | 谁决定 |
| --- | --- | --- |
| 更新器版本（如 2.0.0） | 更新器程序本身的版本，三端统一 | 服主，随程序发布 |
| 内容清单版本（如 1.0.1） | 已发布的 mod 清单版本 | 服主，每次 `publish-client --version` 递增 |

更新器只根据**内容清单版本**判断要不要更新 mod；更新器版本低到不能兼容时才会提示"联系服主拿新版"（退出码 6）。

## 一、怎么更新

1. **先关掉游戏**（游戏开着更新会拒绝执行）。
2. 双击游戏目录里的 **`更新mod.bat`**（Windows）或 **`更新mod.sh`**（Linux/Mac）。
3. 等它跑完。它只会下载有变化的 mod，通常几十 MB，很快。
4. 看到 `=== 更新完成，请手动启动 PCL2 或 HMCL ===` → 自己打开启动器，正常进游戏。

就这些。它不会替你打开启动器，也不会动你的存档、配置和截图。

## 二、它会动什么、不动什么

| 会动 | 不会动 |
| --- | --- |
| `mods/` 文件夹里的 `.jar`（增、删、换） | 你自己装的 mod（默认保留） |
| | `.jar.disabled` 结尾的文件（完全不碰） |
| | mods 以外的任何东西（存档、配置、光影包等） |

## 三、看到失败了怎么办

窗口里会显示一个**退出码**和日志位置。对着下表看：

| 退出码 | 意思 | 你该怎么办 |
| --- | --- | --- |
| 3 | 游戏还开着 | 关掉游戏和启动器里的游戏进程，重新双击 |
| 5 | 网络问题 | 检查网络/代理，重新双击（会自动重试） |
| 4 | 磁盘空间不足 | 清理磁盘后重新双击 |
| 2 | 文件被篡改/验签失败 | 别反复试，联系服主 |
| 6 | 你的更新器太旧了 | 联系服主拿新版更新器 |
| 7 | 配置不对（包标识不匹配） | 联系服主 |
| 10 | 已经有一个更新在跑 | 等它结束，别重复双击 |

详细日志在 `_updater/logs/` 文件夹里，找服主排查时把这个文件夹发给他。

## 四、想回到上一个版本

更新后进不去游戏？双击改成：

```
更新mod.bat rollback
```

（或在终端里运行 `_updater/mcmodsync.exe rollback`）

它会用自动备份把 mods 恢复到更新前的样子。恢复后再联系服主说明情况。

## 五、玩家常见问题

- **我自己装的 mod 会被删吗？** 默认不会。只有服主明确要求"严格模式"时，不在官方清单里的 mod 才会被移除——而且也是被备份而不是直接删除，可以找回。
- **每次都要全量重下吗？** 不用。只有变化的文件会下载，没变的原样保留。
- **版本变旧了（服主回退了）会怎样？** 屏幕会有明显警告，默认照常同步回旧版，这是正常的。
- **Windows 报毒？** 单文件 exe 容易被误报。可以让服主给你 `.py` 版本，或核对包里的 `SHA256SUMS.txt`。
